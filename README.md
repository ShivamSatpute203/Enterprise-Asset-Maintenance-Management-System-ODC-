# Enterprise-Asset-Maintenance-Management-System-ODC-
Cloud-native enterprise asset lifecycle and maintenance platform using OutSystems Developer Cloud

## Overview

Cloud-native enterprise application built using OutSystems Developer Cloud (ODC) to manage assets, preventive maintenance, and work orders.

### Key Features

- Asset lifecycle management

- Automated preventive maintenance scheduling

- Role-based work order management

- KPI dashboard with MTTR & Downtime analytics

- REST API integration

- Background job automation

### Architecture

- Modular ODC architecture

- Core domain separation

- API-first approach

- Asynchronous job processing

### Technical Highlights

- Optimized queries & indexing

- Advanced SQL for KPIs

- Role-based data security

- REST integration

- Scalable background processing
